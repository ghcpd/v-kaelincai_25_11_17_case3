# Baseline Live Panel (Project A)

A minimal, dense Live Interaction Panel demonstrating common UI/UX problems:
- Single page with crammed info
- Weak feedback during actions
- No clear separation of status vs actions

## Start
- `cd Project_A_BaselineLivePanel && ./setup.sh && ./run_tests.sh`

## Tests
- Playwright tests are in `tests/` and use `test_scenarios.json` for scenarios.
