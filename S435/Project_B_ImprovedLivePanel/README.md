# Improved Live Panel (Project B)

An improved UI with:
- Clear separation of status area and action area
- Tabs for Program Interaction / Live Wall / Reservation Queue
- Manual refresh options, optimistic UI, retry flows
- Accessibility: ARIA attributes, keyboard navigation, focus states
- Responsive design with Tailwind CSS

## Start
- `cd Project_B_ImprovedLivePanel && ./setup.sh && ./run_tests.sh`

## Tests
- Playwright tests in `tests/` use `test_scenarios.json` to simulate interactions and assert outcomes.
